## TodoDesktop.spec 解读 + 两个待修问题

- spec 是 PyInstaller 的构建配方（Python 脚本，由 pyinstaller 执行）。关键参数：`EXE(..., a.binaries, a.datas, ...)` 直连 → **onefile 单文件模式**；`console=False` → 无黑框（自启必需）；`upx=True`；`datas=[]` → 未打包 config.json；`name='TodoDesktop'`。
- 问题 1（待修）：onefile 模式下 `__file__` 指向 `sys._MEIPASS` 临时目录，而 `main_window.py` 的 `CONFIG_PATH` 与 `settings.py` 的 `config_path` 都用 `os.path.dirname(__file__)` 定位 → 打包版写配置落到临时目录、退出即被删除，**配置无法持久化**。修复方向：frozen 时改用 `os.path.dirname(sys.executable)`。
- 问题 2：`dist/TodoDesktop.exe` 与 spec 同为 08-31 23:26，而源码最后修改于 09-01 11:15~11:37 → **exe 是旧版本，需重新打包**才能反映最新源码。
- 写入 config.json 的位置与 `settings._build_run_command()` 返回的 workdir 同源，打包模式下 workdir 也会指向临时目录，会影响自启 VBS 的 `WshShell.CurrentDirectory`，需一并核对。
